# FINN

Mobile-first investment agent for the ENAM AI Engineer Build Challenge.

- **Plan:** `PLAN.md` (5 phases, status table, deltas). **Spec:** `BUILD_PLAN.md`. Where they disagree, PLAN.md wins.
- Work one phase at a time, only when asked. A phase is done when its exit criteria pass; report unmet ones plainly.

## Rules (BUILD_PLAN §0, with PLAN deltas)
1. No number is ever generated by an LLM. Numbers come from tables/XBRL, or LLM copying followed by validation.
2. Pull uses primary sources only: no web search, no news, no model background knowledge.
3. Every LLM call goes through `finn.llm.complete_json(tier, system, prompt)` (cached by content hash in `llm_cache`).
4. Degrade per card, never per page.
5. Times stored in UTC, shown in IST. Quarters keyed by period-end date.
6. Secrets live only in `.env` and platform secret stores. Never read `.env` back or print values: these sessions
   are published as build history.

## Layout
- `backend/finn/` library (config, db, llm, sources/fetchers, push/*, pull/*), `backend/jobs/` entry points,
  `backend/tests/`, `backend/api/` (Phase 2).
- `supabase/schema.sql` (idempotent), `supabase/seed_companies.sql` (generated by `scripts/resolve_companies.py`).
- `web/` Next.js PWA. `web/lib/digest.ts` mirrors `backend/finn/push/digest.py`; `backend/tests/fixtures/digest_cases.json` pins both.

## Commands
- `cd backend && ../.venv/bin/python -m pytest -q`
- `cd backend && ../.venv/bin/python -m jobs.poll --since 7d` / `-m jobs.eod` / `-m jobs.warm --freeze`
- `cd web && npm run dev` / `npm test` / `npm run build`
